# 2부 밸런스 점검

2부 다섯 지역의 수치를 사람이 플레이하기 전에 자동 전투로 점검한 기록이다. 자동 플레이어는 단순한 규칙만 쓰므로 사람 플레이를 대신하지 않는다. 지역끼리 상대적인 난이도와 Spawn의 효과를 비교하는 데 쓴다.

## 실행

`Assets/Tests/PlayMode/BalanceSimulation.cs`가 실제 `TurnBattleScene`에서 싸운다. `[Explicit]`이라서 기본 테스트 실행에는 들어가지 않는다.

```bash
"/mnt/c/Program Files/Unity/Hub/Editor/2022.3.34f1/Editor/Unity.exe" -batchmode -projectPath <프로젝트> -runTests -testPlatform PlayMode -testFilter WordVenture.Tests.BalanceSimulation -testResults <결과.xml> -logFile <로그>
```

- 환경 변수 `BALANCE_STAGES`(예: `7,8,9`)와 `BALANCE_RUNS`(기본 3)로 지역과 판 수를 정한다. WSL에서 실행하면 `WSLENV=BALANCE_RUNS:BALANCE_STAGES`로 넘긴다.
- 판마다 결과가 프로젝트 루트의 `balance-report.jsonl`에 한 줄씩 남는다.
- 판마다 카드 순서를 `Random.InitState(1000 × 스테이지 + 판 번호)`로 고정한다.
- 시간을 3배로 빠르게 돌린다. 적 턴 대기(실제 시간 1초)는 줄지 않아서 한 판에 30초~1분 걸린다.

## 자동 플레이어 규칙

1. 워드 HP가 45 이하이고 신성 카드와 Shoot·Drop이 있으면 워드에게 신성 주문을 써서 회복한다.
2. Spawn 정책이면, 아군이 2마리 미만일 때 Spawn과 가장 앞 적에 상성이 좋은 속성 카드로 소환한다.
3. 아니면 Shoot·Drop·Explode와 속성 카드의 모든 조합 중 기대 피해가 가장 큰 것을 쓴다. 기대 피해는 주문 기본 피해 × 상성이고, 남은 HP를 넘는 피해는 세지 않는다. Shoot은 가장 앞 적, Drop은 고른 적 하나, Explode는 고른 적에서 4 unit 안의 적 모두를 맞힌다고 본다.
4. 한 턴에 맞는 쌍이 있는 동안 최대 4번 시전하고 턴을 넘긴다. 40턴을 넘기면 시간 초과로 센다.

## 조정

조정 전에는 뒤틀린 숲에서 피해를 거의 받지 않았고, 최종 보스가 잿빛 유적보다 쉬웠다. 주문 피해는 `10 + 5 × (스테이지 / 2)`라서 스테이지 8·9에서 30인데, 폭발·치유·원거리 슬라임의 HP(25~35)가 주문 한 번이면 끝나는 값이었다. 최종 보스는 언데드 속성이라 신성 주문을 3배(90)로 받아 HP 160이 두 번이면 끝났다.

| 적 | 바꾼 값 |
| --- | --- |
| 폭발 슬라임 (id 26) | HP 25 → 45 |
| 치유 슬라임 (id 27) | HP 30 → 50 |
| 뒤틀린 숲 원거리 슬라임 (id 28) | HP 35 → 50, 언데드 → 바위 속성 |
| 폭주한 마력의 형상 (id 29) | HP 160 → 260, 공격력 12 → 15, 언데드 → 신성 속성 |

최종 보스를 신성 속성으로 바꿔서 번개 주문에 1.5배로 약하고, 신성 주문으로는 회복된다. 신성 주문 하나만 정답이 되지 않는다.

## 해석

- 2부는 서리 마을부터 세계수의 심장까지 턴 수가 늘어난다(14~17 → 27~31). 최종 보스전이 2부에서 가장 길다.
- Spawn은 앞쪽 지역에서 받는 피해를 줄이지만, 카드 한 쌍을 쓰는 만큼 턴이 조금 늘어난다. 최종 보스전에서는 포격과 분열 슬라임이 아군을 쓰러뜨려 다시 소환하느라 오히려 턴과 피해가 늘었다. Spawn이 항상 이득이지는 않다.
- 자동 플레이어는 모든 판을 이겼다. 사람은 카드 조합 실수와 대상 선택 실수가 있으므로 실제 난이도는 이 표보다 높다. 사람 플레이 기록으로 다시 확인해야 한다.

## #119 손패 상한, 적 공격력 상승 적용 뒤

`issue-119.jsonl`은 #119(손패 상한 4장을 주문 카드 2장과 속성 카드 2장으로 나눔, 3턴마다 적 공격력 10% 상승, 턴마다 1장 버리기, 신성 회복은 최대 HP까지)를 적용한 뒤의 기록이다. 정책마다 2판이다. 주문 피해가 예전 자동 상승과 같도록 공격력 업그레이드를 `스테이지 / 2` 단계로 두고, 최대 HP, 손패 상한, 아군 슬라임 업그레이드는 0단계로 두었다(`BALANCE_UPGRADES`로 바꿀 수 있다). 자동 플레이어는 이번 턴에 낼 조합이 없고 어느 한 종류의 손패가 가득 차면 쓸모없는 카드를 한 장 버린다.

| 스테이지 | Spawn | 승리 | 평균 턴 | 평균 받은 피해 |
| --- | --- | --- | --- | --- |
| 3 빗길 (1부) | 안 씀 | 1 / 2 | 16.5 | 130 |
| 4 마왕 (1부) | 안 씀 | 2 / 2 | 18.5 | 127 |
| 5 서리 마을 | 안 씀 / 씀 | 2 / 2, 1 / 2 | 19.0 / 16.0 | 144 / 111 |
| 6 벼락 협곡 | 안 씀 / 씀 | 2 / 2, 2 / 2 | 23.5 / 18.0 | 163 / 53 |
| 7 잿빛 유적 | 안 씀 / 씀 | 1 / 2, 2 / 2 | 25.5 / 23.0 | 125 / 128 |
| 8 뒤틀린 숲 | 안 씀 / 씀 | 2 / 2, 2 / 2 | 24.0 / 22.0 | 135 / 61 |
| 9 세계수의 심장 | 안 씀 / 씀 | 2 / 2, 2 / 2 | 30.0 / 30.0 | 182 / 154 |

- 예전에는 모든 판을 이겼고, 지금은 24판 중 21판을 이긴다. 받은 피해는 대부분의 스테이지에서 예전보다 크다. 신성 회복으로 버틴 판이 많다.
- 중간 과정: 적 공격력 상승이 3턴마다 20%였을 때는 3~6 스테이지를 대부분 졌다. 손패 한도를 종류와 상관없이 4장으로 걸었을 때는 한 장을 버린 뒤 주문 카드만 들어오고 속성 카드가 타는 일이 반복되어 손패가 주문 카드로만 차서 조합하지 못했다. 두 문제를 고친 결과가 위 표다.
- Spawn을 쓰면 6, 8 스테이지에서 받은 피해가 절반 아래로 준다. 아군 슬라임이 근접 공격을 대신 받는다.
- 자동 플레이어는 업그레이드를 고르지 않고 결과 등급도 신경 쓰지 않는다. 사람 플레이 기록으로 다시 확인해야 한다.
