# 속성 상태 효과와 연계

기존 공격 피해에 상태 효과와 연계를 추가한 실험 버전이다. 적 HP와 카드 등장 비중은 이 변경에서 조정하지 않는다. 전체 효과의 재미를 먼저 확인하고 실제 클리어 턴 수·받은 피해를 비교해 수치를 조정한다.

## 상태 규칙

| 속성 | 효과 | 초기 수치 |
| --- | --- | --- |
| 불 | 화상 | 마법 기본 피해에 기존 속성 상성을 적용한 값의 20%, 최소 1. 적 턴 종료 시 발동. Shoot·Explode 2턴, Drop 1턴 |
| 얼음 | 냉기 | Shoot +2점, Drop·Explode +1점. 이동 거리 50% 감소, 2턴 유지 |
| 얼음 | 빙결 | 냉기 3점 소비. 일반 적 다음 행동 1회 취소, 이후 정상 적 턴 1회 동안 재빙결 면역 |
| 번개 | 감전 | 다음 직접 마법 피해 +25%. 1회 소비, 최대 2턴 |
| 바위 | 균열 | 다음 직접 마법이 속성 저항을 무시. 약점 보너스는 유지. 1회 소비, 최대 2턴 |

보스는 빙결 대신 다음 공격 피해 30% 감소를 받는다. 이 약화는 공격한 턴 종료 시 소비하며, 공격하지 않아도 2턴 후 만료한다. 보스 역시 재빙결 면역을 적용한다.

모든 상태와 연계는 확정 적용한다. 같은 화상은 중첩하지 않고 더 높은 피해와 더 긴 지속 시간을 유지한다. 냉기·빙결과 화상은 공존하지 않는다. 불은 냉기·빙결을 지우며 얼음은 화상을 지운다. 신성의 음수 상성은 기존처럼 회복이고, 회복은 감전·균열을 소비하지 않는다.

## 적 고유 속성의 상태 저항

상태를 확률로 무효화하지 않고 같은 속성의 상태 강도를 낮춘다. 기존 피해 상성표는 유지한다.

| 적 속성 | 고유 저항 |
| --- | --- |
| 불 | 화상 피해 50%, 최소 1 |
| 얼음 | 빙결에 필요한 냉기 6점. 적용되는 냉기 점수와 이동 감소는 동일 |
| 번개 | 감전의 다음 피해 증폭이 +12.5% |
| 바위 | 균열이 저항을 절반만 해제. 배율 0.7이면 0.85까지 회복. 약점 배율은 유지 |
| 신성·언데드 | 기존 피해·회복 상성 유지. 이번 버전에서 고유 상태 저항을 추가하지 않음 |

화상은 기존 약점/저항 배율을 따르며 감전 증폭을 다시 받지는 않는다. 균열로 해제된 저항은 후속 불 공격의 화상에도 반영한다. 적 속성과 저항은 내부 전투 규칙으로 적용하며 화면에 설명을 표시하지 않는다.

## 연계

| 먼저 걸린 상태 | 후속 속성 | 이름 | 효과 |
| --- | --- | --- | --- |
| 화상 | 번개 | 불꽃 방전 | 남은 화상 피해 즉시 적용, 화상 해제 |
| 냉기 또는 빙결 | 바위 | 쇄빙 | 후속 마법 기본 피해의 50% 추가, 냉기·빙결 해제 |
| 감전 | 얼음 | 신경 마비 | 감전 피해 증가를 적용하고 다음 적 공격 피해 30% 감소 |
| 균열 | 불 | 용암 균열 | 저항을 무시하고 공격, 새 화상 지속 시간 3턴 |

한 공격에서 이름이 있는 연계는 최대 1회 발동한다. 직접 공격은 기존 감전·균열을 소비하고, 연계를 처리한 뒤 새 속성 상태를 적용한다. 추가 피해·지속 피해는 상태나 연계를 다시 발동하지 않는다.

## 기존 마법과의 연결

- Shoot·Drop·Explode의 이동, 공격 범위, 상성 배율을 유지한다.
- 현재 Explode는 지속 소환물이 아니라 0.5초 동안 나타나는 공격이다. 이 버전에서도 한 시전은 같은 적에게 한 번만 피해와 상태를 적용한다.
- Drop은 현재처럼 충돌한 적에게 적용한다. 광역 판정을 새로 만들지 않는다.
- 시전 및 발사체 처리가 끝나기 전에는 턴 종료를 막아 상태 적용이 적 턴을 걸쳐 발생하는 것을 줄인다.
- 적 턴을 시작한 적만 턴 종료 상태를 소비한다. 새 웨이브의 적은 이전 턴의 만료 처리를 받지 않는다.

## 시각 표현

전투 화면(`docs/images/combat.jpg`), 기존 FirePit·IceShield 픽셀 애니메이션, 슬라임 스프라이트를 참고했다. 생성 이미지는 머리 위 아이콘이 아니라 슬라임 몸에 겹치는 투명 픽셀 아트 오버레이다.

- 투명 여백을 제외한 몸의 경계를 기준으로 너비 1.35배, 높이 1.4배로 표시하고, 이펙트 아래 경계를 몸의 아래 경계에 맞춘다. 같은 sortingLayerID에서 sortingOrder를 본체보다 높인다.
- 화상·서리·빙결 얼음막·감전·균열 순서로 5행 × 4프레임 시트를 사용한다.
- 0.15초 간격으로 프레임을 반복한다. Point 필터, 알파 유지, 무압축으로 가져온다.
- 여러 상태는 동시에 표시하되 냉기와 빙결은 서로 대체한다. 빙결 알파 55%, 나머지 75%로 본체를 남긴다.
- 상태 수치·남은 턴·속성 저항 설명과 마우스 오버 미리보기는 표시하지 않는다. 상태는 몸에 겹치는 이펙트로 전달한다.
- 연계 이름만 발동 시 1.5초 동안 표시하고, 기존 작은 설명 글자보다 두 배 큰 크기를 사용한다.
- 한국어 상태 설명에는 기존 NeoDunggeunmoPro 폰트를 사용한다.

## 이미지 생성

내장 image_gen 도구를 사용했다. 최종 에셋: `Assets/Resources/Combat/ElementalStatusOverlay.png`. 최초 아이콘 시안은 사용하지 않는다.

최종 프롬프트는 `elemental-status-overlay-prompt.txt`에 원문으로 보관한다. 핵심 조건은 기존 저해상도 픽셀 아트에 맞춘 4열 × 5행 투명 시트, 각 셀의 동일한 중심, 슬라임 본체를 그리지 않는 빈 중심, 불꽃·서리·얼음막·전기·균열의 4프레임 반복이다.

## 검증

EditMode 테스트에서 네 연계, 상태 만료, 재빙결 면역, 보스 대응, 회복 상성, 미리보기 비파괴성, 상태 초기화, 투명 시트와 렌더링 순서를 확인한다. 그래픽 장치가 있는 Unity에서는 실제 슬라임 프리팹 3종에 기본 모습과 다섯 상태를 적용하고, 각각 이펙트 4프레임을 렌더링한다.

위치 조정 후 관련 EditMode 테스트 21개가 통과했다. 3종 × 4프레임 렌더링을 직접 확인했으며, 비교 이미지는 `Logs/StatusEffects/VisualReview`에 보관한다.

2026-10-08 Unity 2022.3.34f1의 별도 검증 사본에서 전체 EditMode 64개, PlayMode 7개가 통과했다. PlayMode에서는 실제 Explode 공격의 중복 충돌 방지, 냉기의 이동 거리 감소, 빙결의 적 행동 취소, 화상 턴 종료 처리, 기존 튜토리얼을 확인했다. 최종 렌더링 비교는 `slime-status-overlay-preview.png`에 보관한다.

수치 조정 시작점: `Assets/Scripts/Combat/ElementalStatus.cs`. 실제 플레이 난이도는 자동 규칙 테스트와 별도로 확인한다.
