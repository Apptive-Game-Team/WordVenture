# 2부 그림

2부 지역의 전투 배경 5장, 대화 초상화 5장, 2부 적 슬라임 7종의 프레임 8장씩과 돌진·폭발 슬라임의 예고 프레임 2장씩이다. 경로와 GUID는 `manifest.json`에 있다. 데이터(prefab, 스테이지, 대화)는 이 GUID로 그림을 참조한다.

## 만드는 방법

1. Codex의 내장 이미지 생성 도구로 만든다. 프롬프트 원문은 `prompts/`에 있고, 기존 그림을 화풍 참고 이미지로 첨부했다.
   - 배경: 고원·빗길 전투 배경(`Assets/ThirdParty/ArtResource/JinWook/Desert/HIghland.png`, `Rainy/KakaoTalk_20240701_192204698_02.png`)
   - 초상화: 워드·평원 주민 초상화(`Assets/Art/Story/Portraits/WordDialogue.png`, `VillagerDialogue.png`)
   - 적: 보라 원거리 슬라임 프레임 8장을 생성 규격(1536×1024, 4×2칸, 마젠타 배경)에 맞게 배치한 그림
2. `import_generated.py`가 생성 그림을 게임 에셋으로 바꾸고 `.meta`를 만든다. 저장소 루트에서 실행한다.

```bash
python3 docs/design/act-two-art/import_generated.py <생성 폴더>
```

생성 폴더에는 `bg/`, `portraits/`, `enemies1/`, `enemies2/` 아래에 프롬프트의 파일 이름대로 그림을 둔다.

## 규격

| 종류 | 생성 | 게임 에셋 | 바꾸는 방법 |
| --- | --- | --- | --- |
| 전투 배경 | 1536×1024 | 1024×512 | 가운데 2:1 띠를 잘라 256×128로 줄이고 32색으로 줄인 뒤 4배로 키운다. 기존 배경이 4픽셀 덩어리에 30여 색이다 |
| 초상화 | 1024×1024 마젠타 배경 | 1254×1254 투명 배경 | 마젠타를 지우고 기존 초상화 크기로 키운다 |
| 적 프레임 | 1536×1024, 4×2칸 마젠타 배경 | 512×512 투명 배경 8장 | 좌우를 뒤집고(기존 슬라임 그림은 오른쪽을 본다), 첫 프레임의 폭과 바닥선을 보라 원거리 슬라임 첫 프레임에 맞춘다. 최종 보스는 1.4배 폭 |

## 화풍 맞추기

처음 생성한 배경과 초상화는 세밀하고 색이 많아 기존 그림과 어울리지 않았다. 기존 배경은 색이 31~38개뿐인 단순한 면 그림이고, 기존 초상화는 큰 눈의 애니메이션풍 얼굴에 2단 음영이다. 프롬프트에 이 특징(색 수, 윤곽선 없음, 작은 장식 금지, 가로 띠 구성, 2단 음영, 큰 픽셀 덩어리)을 구체적으로 적어 다시 생성했고, 배경에는 위의 4픽셀·32색 후처리를 더했다.

## 적 슬라임 다시 그리기

생성한 적 프레임은 몸 모양, 눈 위치, 테두리 굵기가 기존 슬라임과 달라서 `build_slimes.py`로 다시 그렸다. 기존 보스 슬라임(악마, 꽃, 선인장)과 같은 방식이다.

- 몸은 보라 원거리 슬라임 프레임 8장을 그대로 쓰고 색 4개(몸, 테두리와 눈, 아래 띠, 반사광)만 바꾼다. 그래서 눈 위치와 프레임마다의 움직임이 기존 슬라임과 같다.
- 개성은 몸 위의 장식으로 준다: 돌진 뿔, 폭발 심지, 치유 새싹, 곡사 포신, 방패, 분열 용암 금, 최종 보스 결정. 장식 한 칸은 2x2칸으로 그려 몸과 같은 굵기의 픽셀이 된다.
- 돌진 슬라임의 예고 프레임 2장은 대기 프레임에 찌푸린 눈썹을 그리고 몸을 눌러 웅크리게 한 것이고, 두 번째 장은 더 납작해지며 뒤쪽에 먼지가 인다. 폭발 슬라임의 예고 프레임 2장은 눈을 찡그리고 심지 불꽃이 커지며, 두 번째 장은 몸이 밝게 번쩍이며 부푼다.
- 최종 보스는 4배 대신 6배로 키워 1.5배 크게 보인다.

```bash
python3 docs/design/act-two-art/build_slimes.py            # 에셋을 덮어쓴다
python3 docs/design/act-two-art/build_slimes.py preview.png # 비교용 그림만 만든다
```
