# 2026-10-15 — 적 슬라임 속성을 생김새에 맞게 변경하고 물·풀 속성 추가

- Date: 2026-10-15
- GitHub Issue: #133
- Status: In Progress

## Goal

- 그림을 보고 약점을 짐작할 수 있도록 적 슬라임의 속성을 생김새에 맞춘다.

## Non-goals

- 슬라임 그림 다시 그리기, 적 HP와 웨이브 구성 변경
- 플레이어 속성 카드 추가 (물과 풀은 적 속성이다)

## Decisions

- 새 적 속성 물(Water)과 풀(Plant)을 `MagicType` 끝에 붙였다(10, 11).
- 물은 얼음·번개에 1.5배로 약하고 불은 1배다. 1부 1~2 스테이지에는 불 카드만 있어서, 불에 강하게 하면 1부 2 스테이지를 깰 수 없다.
- 풀은 불에 1.5배로 약하고 바위에 0.7배로 강하다. 신성은 둘 다 회복(-1)시킨다.
- 바꾼 속성: 0 고양이 신성(하얀 몸, 불로는 지금처럼 1배), 2 1부 1 스테이지 보스 풀, 3 물방울·4 집게·5 물고기 대장 물, 8 선인장 대장 풀, 13 그림자 언데드, 14 슬라임 마왕 불, 20 곡사 바위, 21 돌진 불, 26 폭발 불, 27 치유 풀, 28 숲 고양이 풀.
- 이름은 0 '불꽃 고양이 슬라임'만 '하얀 고양이 슬라임'으로 바꿨다. 나머지는 새 속성과 어긋나지 않는다.
- id 2(1부 1 스테이지 보스)는 지금 어느 웨이브에도 나오지 않아 게임에서는 차이가 없다.
