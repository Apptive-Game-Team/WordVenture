# 2026-10-16 — 후반 보스 공격 연출과 마법 저장 개선

- Date: 2026-10-16
- GitHub Issue: #127, PR #137
- Status: Complete

## Goal
세계수 외피를 75%로 줄여 체력과 예고가 보이게 한다. 정수는 턴별 마지막으로 맞은 속성/형태 마법을 저장하고 3번째 턴에 저장 순서대로 연속 시전한다. 화로 공격, 번개 후퇴 점프, 폭탄의 몸 중심 폭발을 명확히 보여 준다.

## Non-goals
승인된 슬라임 그림 변경, 저장 데이터나 적 ID 변경, 전체 난이도 재설계.

## Context / Constraints
개별 아이콘의 마우스 설명은 해당 속성/형태와 축적 단계만 짧게 표시한다. 적 본체 위에서는 기존 전체 정보를 유지한다.
사용자가 대화에서 다섯 개선을 승인했다. 본체 크기는 유지한다. 기존 마법 프리팹과 상태 규칙을 재사용하고 연속 시전이 끝나기 전에 다음 플레이어 턴이 시작되지 않도록 한다. 무주문 턴에도 저장한 마법을 보존하며 Spawn과 아군 자동 공격은 저장하지 않는다.

- [x] **Step 3: Rollout / Rollback** 기존 PR #137에 검증 화면과 결과를 반영. Draft 유지.

## Validation
- **Commands to run:** Unity 2022.3.62f3 별도 검증 복사본에서 EditMode 전체 및 관련 PlayMode, 실제 전투 캡처.
- **Result:** EditMode 308 통과/1 생략, 전체 PlayMode 128 통과/12 명시적 생략, 최종 관련 전투/캡처 16 통과.
- **Expected output:** 검사 통과, 마법 원본 애니메이션과 속성별 효과, HP/아이콘 화면 내 표시, 피해와 이펙트 도착 시점 일치.

## Risks & Rollback
- 워드는 빙결로 입력을 잃는 대신 보스와 같은 공격 약화를 받고, 아군 슬라임은 실제 빙결 턴을 쉰다. 원소 상태는 기존 ElementalStatus 규칙을 재사용한다.
- **Risks:** 3턴 연속 시전 피해는 보스 공격력의 절반씩에 형태 배율을 적용한다. 실제 플레이에서 난이도 추가 확인이 필요하다.
- **Rollback steps:** 이번 커밋을 revert해 기존 1턴 모방/공격 효과로 복원한다.

## 접목 흡수 연출 후속

- 대상의 실제 그림이 접목 보스 쪽으로 호를 그리며 끌려가고 작아져 몸에 합쳐지는 연출을 추가한다.
- 흡수 중에는 기술 예고를 잠시 유지하고 합쳐진 뒤 가져온 기술의 예고로 바꾼다. 사망/비활성화 시 사본과 빛을 정리한다.
- 사용자 확답에 따라 워드 소환 아군도 흡수한다. 기존 곡사/돌진 대상이 없으면 맨 앞 소환 아군을 지목하고, 다음 턴 흡수 후 그 속성 마법을 한 번 사용한다. 흡수 즉시 아군 대열에서 제거하고 남은 아군은 앞으로 이동한다.

## 공격 거리와 모션 후속

- 일반 근접/기존 근접 보스의 데이터 사거리를 3에서 1.2로 줄인다. 원거리 적은 기존 탄과 사거리를 유지한다.
- 세계수와 대상 없는 접목은 뿌리가 앞줄까지 뻗은 뒤 피해를 준다. 아군 소환수의 원거리 공격도 원거리 모션을 쓴다.
- 아군 흡수/대열 재정렬/대상 사망 취소/속성 마법 명중, 실제 데이터의 근접 접근과 원거리 공격, 뿌리의 지연 명중과 사망 정리를 검증한다.
