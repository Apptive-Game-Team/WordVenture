# 2026-10-16 보스 전투 피드백

- 나무 형태는 기존 크기의 75%다. 체력 글자 크기는 유지하고 위치를 내려 체력과 뿌리 예고가 화면 안에 보인다. 정수의 그림과 크기는 유지한다.
- 정수는 턴마다 마지막으로 맞은 속성/형태 주문 하나를 저장하고 3번째 턴에 순서대로 시전한다. 무주문 턴에는 저장분을 보존하며 Spawn/아군 타격은 제외한다. 각 주문은 보스 공격력의 절반에 기존 형태 배율을 적용한다.
- 실제 플레이어 마법 15종의 프리팹/애니메이션을 재사용한다. 화상, 냉기, 감전, 균열과 원소 반응도 기존 ElementalStatus 규칙을 사용한다. 워드는 빙결 대신 공격 약화를 받아 입력을 유지하고, 아군은 빙결된 행동을 쉰다.
- 화로는 불씨를 모아 큰 파동을 발사하고 도착한 순간 피해와 타격 효과/음을 낸다. 열기 3에서 더 큰 파동과 충격을 낸다.
- 번개 보스는 돌진 다음 턴 탈진하고, 회복 턴에는 뒤로 도약해 착지하면서 예고한다. 그 다음 턴 바로 돌진한다. 도약 착지는 화면 안으로 제한된다.
- 폭탄은 몸 중심에서 최소 5월드/몸 폭 2배 이상의 폭발을 낸다. 불티/섬광/바닥 먼지와 소리가 함께 나오며 피해 반경은 유지한다. 원본 그림의 투명 여백은 docs/design/combat-effects/build_enemy_magic_bounds.py가 계산한 알파 경계로 보정한다. 기존 이미지 100프레임의 메타데이터만 추가했고 원본 그림은 수정하지 않았다.
- 개별 아이콘 위에서는 해당 속성과 행동/축적 단계만 짧게 설명한다. 적 몸 위에서는 기존 전체 정보를 표시한다.

## 실제 실행 증거

Unity 2022.3.62f3 TurnBattleScene의 보스 생성/행동 fixture 캡처다. `boss-attacks.gif`는 화로 방출, 불 Drop/얼음 Shoot/번개 Explode 연속 시전, 후퇴 도약, 폭탄 폭발을 보여 준다. 19는 세 주문 저장, 20~22는 각 마법, 23~24는 도약/착지, 25는 몸 중심 폭발, 26은 아이콘별 짧은 설명이다.

캡처는 SpawnExtraEnemy/RememberElement/PlayTurnAction을 직접 호출한다. `worldtree-smaller.gif`는 첫 전투 시간을 줄이고 정상 Kill 경로로 변신시켰다. 전체 지역을 처음부터 수동으로 플레이한 영상은 아니다. 실제 TakeSpellHit 저장, Spawn 제외, 무주문 보존, 아군 보호/속성 효과, 사망 취소와 턴 대기는 별도 자동 검사로 확인했다. GIF에는 소리가 포함되지 않는다.

## 검증

- `-batchmode -nographics -runTests -testPlatform EditMode`: 308 통과, 그래픽 장치가 필요한 검사 1 생략.
- 관련 PlayMode 42개 통과. 최초 1개 실패는 화면 내 착지 제한에 맞춰 fixture를 보정했고 다시 전부 통과했다.
- 최종 공통 마법/아이콘 설명 포함 전체 PlayMode: 128 통과, 실패 0. 명시적 검사 12개 생략.
- 최종 낙하 표시 정리 후 ActTwoLateEnemyPlayTests와 WorldTreeEntranceCaptures: 16개 모두 통과. 별도 캡처 4개가 포함된다.
- 보스 외형/도감/번역 참조 검사 통과. 전체 PlayMode에 기존 아군 역할, 주문, 턴, 적 정보창, 2페이즈 검사가 포함된다.
- 실행별 수치/생략과 최초 실패 이유는 `validation.json`에 기록했다.

## 직접 플레이 확인

Draft를 Ready로 바꾸기 전에 3턴 공격의 난이도, 효과음 크기, 점멸/타격감과 여러 적이 함께 있을 때의 가독성을 확인한다. 전 지역 수동 완주와 플랫폼별 빌드는 이번 변경에서 실행하지 않았다.

## 접목 흡수 후속

기존 보스 편 곡사/돌진 슬라임의 흡수 연출이다. 대상 그림이 보스 쪽으로 끌려가며 작아지고 몸 안으로 합쳐진 뒤 가져온 기술의 예고를 표시한다. 흡수 판정은 기존과 같이 대상 비활성화로 처리하고 그림 사본에는 적 태그/충돌/공격 기능을 두지 않았다. 흡수 연출 중 턴 대기, 사망 취소, 기술 1회 소비와 실제 캡처를 포함한 관련 PlayMode 20개 통과. GIF의 첫/끝 정지 화면만 읽기 쉽게 늘렸다.

27은 지목, 28은 끌려오는 몸, 29는 합쳐지는 빛, 30은 포격 준비다. 사용자 확답에 따라 곡사/돌진 대상이 없으면 워드의 맨 앞 소환 아군도 지목한다. 흡수 즉시 대열에서 빠지고 남은 아군이 이동하며, 다음 턴에 흡수한 아군의 속성 마법을 한 번 쓴다.


## 소환 아군과 공격 거리 후속

31~34는 소환 아군 지목, 끌어오기, 속성 예고와 실제 속성 탄이다. 35는 세계수에서 앞줄로 뻗는 뿌리, 36~37은 일반 근접 적의 접근 전과 거리 1.2에서의 공격이다. `ally-graft-absorption.gif`와 `worldtree-roots.gif`는 실제 전투 씬의 fixture 행동을 캡처했다. GIF는 소리가 없으며 전체 지역 수동 완주를 증명하지 않는다.

근접 및 기존 근접 보스 데이터 16개의 사거리를 3에서 1.2로 바꿨다. 실제 원거리 탄, 곡사, 돌진, 폭발은 고유 사거리/명중 방식을 유지했다. 세계수와 접목의 기본 공격은 뿌리가 도착해야 피해를 주고, 소환 아군은 원거리 모션으로 투사체를 발사한다. 짧아진 근접 사거리로 일부 적은 접근에 한 턴 더 쓸 수 있으므로 실제 난이도 확인이 남는다.


후속 최종 검증: EditMode 308 통과/1 GPU 생략, 전체 PlayMode 136 통과/14 명시적 생략. 뿌리 그림을 다듬은 후 관련 전투/새 캡처 32개 재실행 통과. 소환 아군 흡수와 근접 접근의 실제 난이도, 여러 적이 겹친 화면은 직접 플레이 확인 사항으로 남긴다.
