# 보스 행동 아이콘 검증

승인된 기획에 따라 상시 문장 예고를 픽셀 문양과 단계 표시로 교체했다. 눈덩이 성장, 돌진/탈진, 열기, 흡수 대상 연결, 뿌리 공격, 카드 원본을 재사용하는 모방 마법을 표시한다. 즉시 실행할 행동은 문양과 테두리가 맥동한다. 설명과 피해 수치는 기존 적 정보창에서 마우스를 올릴 때만 나온다.

Unity 2022.3.62f3의 실제 TurnBattleScene에서 보스를 생성하고 행동을 호출한 PlayMode fixture 캡처다. 전체 지역을 처음부터 플레이한 결과는 아니다. 비행과 변신은 정상 Play/Kill 경로를 호출했다. 01~12의 세계수 연출 순서는 유지하며 아이콘만 새 표시다.

- 전체 EditMode: 308 통과, 그래픽 장치가 필요한 검사 1 생략.
- 관련 PlayMode: 43 통과. 지역 보스, 후반 적, 2페이즈, 기존 적 정보창, 비행 취소/복원, 명시적 화면 캡처 포함.
- 최종 위치 간격 보정과 피격 효과 종료 후 재캡처: 지역 보스/명시적 캡처 17 통과.
- 체력이 그대로인 상태의 설명 갱신, 한국어/영어 전환, 크기/방향 불변, 아이콘 영역의 마우스 감지, 파괴된 눈덩이와 흡수 대상 표시 정리를 검사했다.

`validation.json`은 각 실행 결과의 요약이다. 14/15는 한국어/영어 마우스 설명이며, 13의 세 화면은 Shoot/Drop/Explode 모방이다. 개발자가 Draft를 Ready로 바꾸기 전에 실제 플레이에서 단계별 가독성과 맥동 속도를 확인한다.
