# 후반 보스 검증 자료

Unity 2022.3.62f3, 별도 사본 `Logs/BossValidation`에서 검증했다.

## 실제 화면

`worldtree-two-phase.gif`는 전투 씬에 id35를 직접 생성한 뒤 정상 Kill 경로로 쓰러뜨린 연속 캡처다. 마력 전환과 본체 생성은 런타임 코드를 그대로 사용했다. 지역 보스 및 모방 예고 화면은 전투 씬에서 해당 적의 행동을 직접 호출했다. 전 지역을 처음부터 플레이한 영상은 아니다. 개발 SDK의 키 입력 계기만 캡처에서 제외했다.

- `00-worldtree-slime-phase-one.png`: 나무를 닮은 거대 슬라임
- `01-fallen-shell.png` ~ `04-core-congealing.png`: 시체 붕괴, 노란 액체, 웅덩이, 응집
- `05-tiny-core-pinprick.png` ~ `10-core-battle-ready.png`: 작은 별빛, 섬광, 비행, 착지, 이름, 전투 복귀
- `07-snowball-ready.png` ~ `12-graft-mortar.png`: 지역별 예고 상태
- `13-worldtree-echo-*.png`: 마지막 공격 주문의 모방 예고

## 자동 검사

- EditMode: 300개 중 299개 통과, 1개 명시적 검사 생략.
- 전체 PlayMode 최초 실행: 103개 중 94개 통과, 1개 실패, 8개 생략. 실패는 나레이션 추가로 줄 수가 66에서 67로 바뀐 고정 기대값이었고 수정했다.
- 후속 집중 검사: 위 대사 검사, 지역 보스, 변신, 등장, 명시적 캡처 22개 모두 통과. 화상 사망이 시작한 변신 동안 새 턴이 시작되지 않는 경우도 포함한다.
- 참조·프리팹·번역·픽셀 규칙 감사: `static-validation.json`, 오류 0, 적 7종, 프레임 41개.

최종 시각 수정 이후 검증 결과와 자동 전투 결과는 아래에 추가 기록한다. 자동 전투는 고정 시드와 단순 선택 규칙을 사용하며 사람이 기믹을 판단하는 플레이나 통계적 난이도 검증을 대체하지 않는다.

## 원본과 처리

`*-raw.png`, 프롬프트, 처리 스크립트와 `*-logical.png`는 아트 생성 근거다. 게임에 사용하는 이미지는 `Assets/Art/Combat/Enemies/ActTwo`의 프레임이다. 기존 Surge 아트는 2페이즈에서 그대로 사용한다. 원본의 공용 사망 프레임 대신 전환 UI에서 첫 형체를 무너뜨려 사망을 표현한다.

## 높은 업그레이드 빌드 표본

시드 9000, 최종 지역 9 전체 전투, 업그레이드 `(공격력 6, 최대 HP 5, 손패 2, 아군 3)`에서 두 가지 선택 규칙으로 검증했다. 소환 사용은 33턴/잔여 HP 28, 소환 미사용은 33턴/잔여 HP 40으로 모두 클리어했다. 피해·회복·시전 수는 `balance-final.jsonl`에 기록했다. 한 시드의 성공 사례이며 지역별 여러 빌드의 균형을 보장하지 않는다. 이전 수치의 표본은 `balance-before-two-phase.jsonl`로 구분했다.

- 최종 시각 수정 후 변신 회귀·캡처 8개 모두 통과. 상단에 중복된 사망 프레임을 제거하고 전환용 형체만 무너뜨렸다.
