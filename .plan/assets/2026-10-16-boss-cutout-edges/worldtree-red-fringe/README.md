# 세계수 잎의 붉은 경계 추가 정리

1차 누끼 정리 후에도 잎 바깥쪽에 연속된 붉은 주황색 선이 남았다. 일반 투명 마스크가 보존했던 유색 테두리여서, 이번에는 잎에 인접한 녹슨 색 경계를 별도로 정리했다.

내장 imagegen에 해당 테두리만 제거하도록 요청했다(`input.png`, `generated.png`, `prompt.txt`). 생성 결과의 잎 영역을 참고해 원본 521257d의 녹색 잎과 인접한 붉은 주황색 외곽만 투명 처리했다. 생성 결과의 RGB는 사용하지 않는다. `refine.cjs --apply`로 재현하며 Node/sharp와 `WORDVENTURE_SHARP` 설정 방법은 상위 README와 같다.

세계수 8프레임에서 2,359개 경계 픽셀을 추가로 정리했다. 녹색 잎과 밝은 금빛 수액에 쓰는 색은 제거 대상에서 제외했다. 원본과 크기/남아 있는 픽셀 RGB/이진 알파가 같음을 별도로 대조했다. 프리팹과 .meta는 바꾸지 않았다.

`canopy-before-after.png`는 실제 게임 PNG의 잎 부분을 6배 확대한 것으로, 위는 521257d 상태이고 아래는 이번 결과다. `frames-before-after.png`도 위 두 줄이 이전 상태, 아래 두 줄이 수정 후 8프레임이다. 생성기의 중간 PNG를 게임에 넣은 결과가 아니다.


Unity 2022.3.62f3 실제 세계수 등장/전투 캡처 PlayMode 1개 통과. `battle.png`를 수동 확인했다. 이미지 8개만 수정해 전체 EditMode/PlayMode 행동 검사는 이번 후속에서 재실행하지 않았다.
