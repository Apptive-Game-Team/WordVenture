원본 생성 크기 1672×941. 기존 배경의 월드 너비 4.8을 유지하도록 Pixels Per Unit 348.33333333을 사용. Point 필터, 무압축, mipmap 비활성화. 기존 프레임 애니메이터는 스프라이트 덮어쓰기를 막기 위해 비활성화하고 Controller 참조 제거.

생성 원본은 픽셀아트처럼 보이지만 격자가 맞지 않고 안티앨리어싱과 노이즈가 섞여 있어(색 12만~25만 개), 프로젝트 픽셀 기준(아트 1픽셀 = 1080p 화면 4px, `.agents/skills/pixel-art/SKILL.md`)에 맞춰 `pixelate.py --display 1920x1080 --despeckle`로 480×270, 64색 이하로 변환. 1텍셀 = 1아트픽셀로 저장하고 Pixels Per Unit 100으로 월드 너비 4.8 유지.
